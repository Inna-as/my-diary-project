Точка вкуса (Умный холодильник)
Кулинарный веб-сервис для поиска рецептов, подбора блюд по имеющимся ингредиентам и публикации рецептов с активным взаимодействием сообщества.

Ключевые идеи проекта:

поиск рецептов по названию, описанию и ингредиентам;
подбор блюд по тем продуктам, которые есть в наличии;
определение недостающих продуктов и возможность перехода к покупке;
публикация рецептов, избранное, комментарии и модерация контента.
Быстрое начало
Установите Python 3.x и PostgreSQL.
Создайте виртуальное окружение и активируйте его.
Установите зависимости:
pip install -r requirements.txt
Сконфигурируйте переменные окружения (секретный ключ, база данных, режим отладки).
Примените миграции:
python manage.py migrate
Создайте суперпользователя:
python manage.py createsuperuser
Запустите локальный сервер:
python manage.py runserver 8000
Примечание: при разработке можно использовать файл .env для хранения секретов и настроек подключения к БД.

Архитектура и данные
Основная сущность: Recipe (в коде может называться Article)
Модели:
CustomUser (пользователь)
FoodCategory (категория ингредиентов)
Ingredient (ингредиент)
Article/Recipe (рецепт)
RecipeIngredient (промежуточная связь рецепта и ингредиента с amount и unit)
FavoriteRecipe (избранное)
Comment (комментарий)
CommentReport (жалоба на комментарий)
Взаимодействие:
Комментарии могут иметь ответы (самоссылочная связь через parent)
Комментарии проходят модерацию: is_approved, is_spam, auto_approved, report_count
AJAX-операции для лайков, комментариев и т.д.
Архитектура: MVC/MVT (Django) с разделением моделей, представлений и шаблонов; использование ORM для связей; AJAX для динамических действий.

Как работает модерация комментариев (кратко)
Комментарий отправляется авторизованным пользователем.
Функционирует авто-модерация на основе анализа текста и поведения пользователя (спам, ссылки, количество одобренных комментариев и т.д.).
Возможны состояния: одобрен автоматически, отправлен на ручную модерацию, заблокирован как спам.
Поля статуса модерации: is_approved, is_spam, auto_approved, report_count.
Жалобы на комментарии хранятся в CommentReport.
